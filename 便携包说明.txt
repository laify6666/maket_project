在线商城 - 绿色便携包
========================

一、使用方法
1. 把整个项目文件夹复制到任意 Windows 电脑（不需要安装 Python 和 Django）。
2. 双击 start.bat。
3. 自动完成数据库初始化和演示账号创建。
4. 浏览器打开 http://127.0.0.1:8000/

二、演示账号
- 卖家：seller / seller123456
- 买家：buyer / buyer123456

三、常用命令（在项目目录打开 cmd）
manage.bat runserver             启动网站
manage.bat createsuperuser       创建管理员
manage.bat clear_business_data   清空商品/订单等业务数据
manage.bat seed_demo             创建演示账号

四、重要目录
runtime\     内置 Python 解释器，不要删除
.deps\       项目依赖，不要删除
media\       商品图片上传目录，首次使用会自动创建
db.sqlite3   数据库文件，首次启动自动生成

五、注意事项
- 第一次启动请等待 cmd 窗口显示服务器启动信息，再打开浏览器。
- 关闭网站：关掉 cmd 窗口即可。
- 换电脑时复制整个文件夹即可，包括 runtime 和 .deps。
- 不要删除 runtime 或 .deps，否则无法运行。
